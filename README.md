# Til helvete

A 3D browser game set in a rainy Oslo. Rent an e-scooter, smash café tables and electric cars, dodge trams and buses, and outrun the neighbourhood Facebook group.

**Play:** open `index.html` in a browser, or visit the GitHub Pages site for this repo.

## Controls

| Action | Keyboard | Phone |
|---|---|---|
| Throttle | W / ↑ | Gass |
| Brake / reverse | S / ↓ | Brems |
| Steer | A D / ← → | ◀ ▶ |
| Boost | Shift / Space | Boost |
| Horn | H | Tut |
| Sound bomb | B | Bombe |
| Sound on/off | M | Lyd |

## Tech

Three.js (r128 from cdnjs), a procedurally generated city, hand-written collision, Web Audio synthesis for all sound effects, and the browser's speech synthesis for the Norwegian voice lines. No build step, no assets: everything is in one HTML file.

Inspired by *Baper Rasta* by Omar Faruqe Riyad.
